# Templates (`templates`)

## Purpose

Templates provide consistent starting points for completed archive documents
and directory indexes.

## What belongs here

Keep one light scaffold for each document role and a separate scaffold for the
exhaustive directory README shape. Templates contain braced placeholders and
are not completed archive documents until copied and filled in.

## Index

### Subdirectories

- None yet.

### Templates

- [Directory README template](directory-readme.md) — an exhaustive local
  inventory for a new archive directory.
- [Inquiry template](inquiry.md) — an active question, hypotheses, evidence,
  and outcome.
- [Journal template](journal.md) — a dated research or reflection entry.
- [Map template](map.md) — a selective route through related archive material.
- [Note template](note.md) — an idea or synthesis in the author's own words.
- [Source template](source.md) — a bibliographic record and evidence-focused
  reading note.
- [Specification template](specification.md) — a versioned language chapter
  whose `MAJOR.MINOR.PATCH` placeholder must be replaced with the approved
  slice identifier, with normative rules, visible authority labels,
  diagnostics, and non-normative evidence.

## Maintaining this index

Update this page whenever a template is added, renamed, or its intended use
changes. Keep document metadata aligned with
[`frontmatter.schema.json`](../frontmatter.schema.json) and authoring guidance
aligned with [`AGENTS.md`](../AGENTS.md).
