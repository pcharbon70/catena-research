# Archived Inquiry: How Should Catena Preserve Principal Inference While Extending HM?

## Why this matters

The former inquiry assumed that an existing Catena language extended an HM
core and asked how its implementation could preserve principality. That premise
is outside the greenfield research boundary.

## Operational question

This archived record asks only whether the old question should remain active.
It should not: both its assumed feature set and its implementation-facing paths
were derived from a superseded repository reading.

## Working hypotheses

- No claim from the old inquiry should constrain the greenfield design.
- Independently supported HM results remain available through the rewritten
  foundation note.

## Paths to explore

None. New research belongs in the replacement inquiry.

## Findings

The language name can be retained without retaining the old language model.
The fresh proposal now derives its feature boundaries from primary literature
and explicit design criteria.
