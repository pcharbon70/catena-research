# C028 API and ABI Compatibility

## Observations

Checklist item G028 is complete as C028 and normative source-only
language revision `0.1.24`, closing Section 3 — names, modules,
packages, and separate compilation — entirely. The completed boundary
fixes the four compatibility layers (real source and interface rules;
declared behavior absence — the kernel is the contract, no
bug-compatibility; declared BEAM ABI absence — representation is not a
surface); version meanings (breaking requires SemVer major at 1.0.0+
and minor below it under the Cargo 0.x rule C025 already fixed for
operators; edition bumps are the language-level instrument); the
strict fifteen-row breaking matrix over decoded interfaces; the formal
re-export-facade exclusion closing the C022/C025 deferral; joint and
bundle digests as identity-only; and claim validation with
`CMP001`–`CMP003`.

Two implementation decisions worth recording. First, the classifier
consumes the *decoded* interface form (structs — `Scheme`, effect
`Row`, decoded datatype and handler records) rather than raw JSON:
digest-verified interfaces are already the only cross-package contract,
and decoding through the shipped `Interface` boundary means malformed
input surfaces as `CMP002` instead of a crash. Equality compares
canonical fingerprints — `Entry.render_type` for types and schemes,
rendered occurrence keys for row entries — rather than raw structs,
keeping classification independent of map ordering or struct field
evolution. Second, a different interface identity (origin or module)
is `CMP003` unclassifiable drift rather than an everything-breaking
verdict: two modules are simply not comparable, and guessing would
invent a rule the matrix does not define. The `0.x` claim semantics
reuse C025's vendored SemVer precedence (`Deps.compare`) so the claim
side and the operator side can never disagree.

This promotion also repairs the stale `G027` deferral pointers that
C027's promotion left in sibling chapters and maps (nine locations
across files-and-modules, imports-and-exports, package identity,
prelude policy, module cycles, and their maps), alongside the living
`G028` pointers (twenty-two locations) — the same maintenance duty the
C026 checklist repair served. Historical notes, inquiries, and
journals keep their era-accurate references by design.

## Evidence

The compiler adds the new `Catena.Package.Compat` module with
`diff/2` (fifteen-row matrix over decoded interfaces with itemized
reasons), `diff_entries/2` (manifest entry-set rows 13–15), and
`validate_claim/3..4` (SemVer claim validation with the 0.x and 1.0+
rules, `CMP001` under-claims, `CMP002` malformed shapes including
non-increment claims, `CMP003` identity drift); the `0.1.24` revision
registration in `LanguageVersion` and the lifecycle registry; and the
`guides/language/api-compatibility.md` guide. No manifest, interface,
or artifact format changed.

The focused corpus covers exact selection, lifecycle registration, and
pinned predecessor defaults (the namespace resolver stays pinned at
`0.1.22`, `decode_source_text` advances to `0.1.24`); every matrix
family — export removals, renames, scheme changes, additions, effect
row widening (breaking) and narrowing (minor), datatype and
constructor changes, trait/instance/handler changes; entry-set rows
(additions minor, removals and result changes breaking, marker
movement minor); claim validation across the 0.x Cargo rule and the
1.0+ major rule in both valid and under-claiming directions including
the combined interface-plus-entries claim; `CMP002` for undecodable
input, empty maps, malformed and non-increment claims; `CMP003` for
moved identities; the declared absences (same interface content with a
different digest or a different body value stays unclassified;
representation-only changes never break); determinism; and reused
`PKG001` family stability. One test round-trips two real compiled

works on shipped artifacts.

## Version and boundary decision

C028 consumes `0.1.24` for the layer stances, version meanings, the
matrix, the facade exclusion, and `CMP001`–`CMP003`. No manifest
field, interface version, artifact version, or signed format changes;
the classifier is a pure consumer of shipped interfaces. Every
predecessor API retains its exact selection. The next unused semantic
patch is `0.1.25`.
