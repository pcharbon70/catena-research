# C140 Excluded Advanced Type Features

## Observations

Checklist item D140 is complete as C140, normative source-only
language revision `0.1.44` (85/141 total) — and with it **Section
7 completes at 10/10**, the first whole section closed since
Section 4. The completed boundary: the seven excluded forms
(impredicative instantiation, inferred higher rank, first-class
existential packages beyond declared constructors, general linear
types, dependent types, unrestricted type families, higher-kinded
polymorphism over arbitrary kinds, unrestricted GADT inference)
stay excluded from edition `0.1` — C001's `0.1.1` exclusions
restated as routing rows, unchanged — and the **seven-point
arrival gate** (problem statement, repeated-use evidence,
interaction audit, formal semantics, operational contract,
diagnostic story, library comparison) becomes normative text,
adopted verbatim from the remaining-areas discipline. C068's
checked profile stays unchanged; no omnibus advanced-features
revision is admitted. Zero new diagnostic families, no new public
API, no checker rule changes.

Two implementation notes. First, the **profile-boundary
diagnostics are live and pin cleanly**: an excluded type spelling
rejects as `T012` (the frozen grammar is the boundary), an
unannotated GADT-matching definition rejects as `T010` (the exact
C001 rule — though reaching it requires the definition to be
unexported, or `T008` fires first), and existential escapes
reject as `T009`. Second, the **positive-complement witness
reused the C002 GADT corpus shape** and re-learned two standing
facts: the 0.1.2 grammar spells quantifiers with name-based
forall and no `uses` key, and named-field constructor declarations
require named-field patterns and constructions (the C042 lesson).

The sibling compiler implementation is commit
[`77fba75`](https://github.com/pcharbon70/catena/commit/77fba75)
on branch `agent/c140-advanced-exclusions`, publication pending:
the compiler PR merges into `rewrite` first, then this research
promotion merges, following the established publication order.
