# C066 Name Resolution

## Observations

Checklist item G066 is complete as C066, normative source-only
language revision `0.1.42` (83/141 total), Section 7's third
closure (8/10). The completed boundary is one invariant over four
standing pillars: name resolution is **type-independent** — every
name resolves as a function of scope structure alone (C021's
model), annotations never change a name's target, and results
never depend on elaboration order. The five-way classification:
field labels are not resolved names (`select` is a typed
operation); trait method names resolve by scope with **instance
selection classified as evidence selection** — settled at the
instance under coherence, never deferred to a call site;
constructors are declaration-scoped by visibility; literals
self-describe by spelling; operators instantiate over the closed
set with no name choice. The four exclusions — overloading by
type, expected-type adaptation, call-site ambiguity deferral,
inference-directed field access — are amendable only by a revision
that amends the classification table explicitly. Zero new
diagnostic families, no new public API, no checker rule changes.

Two implementation notes. First, the **obligation code was renamed
mid-slice**: the chosen three-letter `NMR` collided with the
validator's two-letter `AREA-OBL-NNN` identifier contract — the
uniform shape across all forty-two predecessor areas — so the code
became `RN` rather than relaxing a corpus-wide contract for one
area; the decision register records the adjustment. Second, the
**witnesses leaned on standing corpus facts**: kernel calls
require an argument (the C047 finding), in-module construction
over an `abstract` export is legal (C022 — visibility binds
outside the defining module), and missing trait evidence rejects
at the instance as `TRT005`, which became the evidence-side
witness together with the running instance call.

The sibling compiler implementation is commit
[`bef5fd5`](https://github.com/pcharbon70/catena/commit/bef5fd5)
on branch `agent/c066-resolution`, publication pending: the
compiler PR merges into `rewrite` first, then this research
promotion merges, following the established publication order.
