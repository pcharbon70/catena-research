# C082 Top-Level Effects

## Observations

Checklist item G082 is complete as C082, normative source-only
language revision `0.1.48` (89/141 total), Section 9's seventh
closure (7/8 — only G080 remains). The completed boundary: **the
silent top level** — an application entry point leaves nothing
unhandled (effect-closed, `ENT001`, C027 unchanged), nobody
interprets unhandled requests because none exist (no ambient host
handler exists or is reserved), and launch is invocation only (to
completion under unchanged kernel semantics, no scope, no
injection; return is shutdown). The capability interface for
G106: capabilities reach an entry only as explicit typed values
through a channel G106's slice defines and justifies — deny-able,
never ambient — with the zero-argument and effect-closed rules
binding until then. G084's supervision interprets process failure,
never requests. The door: entry-form widening amends C027
explicitly with who-interprets-what stated. Zero new diagnostic
families, no new public API, no checker rule changes — the
smallest slice type on the board (the C140 shape), fittingly for
the question C027 had already answered in passing.

Two implementation notes. First, the **witness corpus is entirely
C027's shapes**: the launch re-pin (an effect-closed `main`
package compiled through `Linker.compile_manifest` and launched
twice to `{:ok, %{status: :completed, value: 8}}`) and the
boundary's negative witness (`Entry.validate` rejecting a
non-effect-closed export as `ENT001` with reason
`not_effect_closed`). Second, three **module-alias facts** worth
keeping for future entry-corpus tests: `Row` lives at
`Catena.Effect.Row`, `Scheme` at `Catena.Type.Scheme`, and the
linker at `Catena.Package.Linker` — a first draft using bare
`Catena.Row`/`Catena.Linker` failed to compile before the fixes;
the manifest also requires the full field set (`interfaces`,
`roots`, `output`, `assurance`) beyond the minimal shape.

The sibling compiler implementation is commit
[`e962b73`](https://github.com/pcharbon70/catena/commit/e962b73)
on branch `agent/c082-toplevel`, publication pending: the compiler
PR merges into `rewrite` first, then this research promotion
merges, following the established publication order.
