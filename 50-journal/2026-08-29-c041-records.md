# C041 Structural Records and Variants

## Observations

Checklist item P041 is complete as C041 and normative source-only
language revision `0.1.36`, Section 5's second closure (4/8). The
completed boundary fixes: the seven-operation table — record literal,
select, update, extend, restrict, variant inject, and match —
elevated from the kernel with cited homes; literals are closed
unique-label rows with duplicate labels static invalidity; written
field order controls evaluation order (C030) and never equality,
comparison, or row identity (C035/C037); extend and restrict
produce closed rows over closed inputs; open tails exist only in
type positions, composing row polymorphism through signatures;
missing-label operations are statically unreachable; records are
semantic maps with invisible representation; and the kernel
S-expression path is the only frontend expressing the operations
until P109. Zero new diagnostic families and no new public API.

Three implementation decisions worth recording. First, the **witness
fixture is the C010 fixture's shape, adapted**: the same
literal→update→select→extend/restrict→select chain plus variant
dispatch, closed over a self-contained module — the first draft's
string-replacement scaffolding collapsed into a paren imbalance
(the kernel parser's honest `unclosed parenthesis` report), and the
clean rewrite declares the program directly. Second, the **row-tail
witness reads the kernel core's signature**: the typed core carries
definitions' `signature` (not `scheme` — the kernel and typed-core
record shapes differ; the C035 classifier's `Data.comparable_type?`
consumes the latter, the fixture the former), and
`{:variant, %{fields: fields, tail: nil}}` with left→Int and
right→Bool demonstrates type-position composition over closed
records. Third, the **value-level equality witness uses Elixir map
equality directly** (`%{a: 1, b: 2} == %{b: 2, a: 1}`) rather than
`Values.compare` — C035 defined comparability for records as
structural recursion in `comparable?`, but `compare/2` covers the
orderable primitives only (Int, Float, and since C040 the binary
content orders); map equality at the witness level tests exactly the
order-irrelevance claim without inventing a record `compare` the
corpus never defined. The BEAM-side round-trip asserts selected
values (`{2, true, 41}`), never map shapes — representation is
invisible by contract.

## Version and boundary decision

C041 consumes `0.1.36` for the operation table, the row model, and
the representation clause; it adds no JSON AST version, kernel
S-expression version, interface version, artifact version, signature
domain, typing rule, runtime behavior, BEAM representation, manifest
field, public API name, or diagnostic family, and amends no retained
revision — the kernel's record calculus stays frozen at 0.1.8. Every
predecessor API retains its exact selection. The next unused
semantic patch is `0.1.37`.
