# C029 Values and Evaluation

## Observations

Checklist item P029 is complete as C029 and normative source-only
language revision `0.1.25`, opening Section 4 (core expressions and
evaluation). The completed boundary fixes the closed ten-form value
grammar — the kernel's nine forms plus Float with C018 semantics
unchanged — with the closed non-value list (evidence, handler
declarations, capability names, resumptions, traps, effect rows,
signatures); uniform first-classness with G037/G085 observability
named as exclusions rather than tiers; the G040 entry rule (each
future type enters with its value status in its own slice); the
strictness invariant — every subexpression evaluates at most once, to
a value or a terminal trap, before use — with the kernel's `and`/`or`
right-operand skips as the only named exceptions and a C008
edition-record gate against any future lazy or multi-evaluation form;
and value-or-trap terminal outcomes with suspended requests as pending
continuations. The slice is definitional: zero new diagnostic
families.

Two implementation decisions worth recording. First, the classifier
consumes two concrete carriers — typed-core expression forms (maps
keyed on `tag:`) and kernel runtime values (the shapes the stepper
places in value control: `{:closure, …}`, `{:catena_variant, …}`,
`{:catena_constructor, …}`, `{:catena_process, …}`, records, tuples,
primitives) — rather than inventing a third representation. Trap
3-tuples classify by their head before the generic tuple recursion, so
a trap carrying a value payload is still a trap and never misreads as
a value. Second, non-value reasons key on shipped carriers where they
exist (`Catena.Effect.Row` → effect row, `Catena.Type.Scheme` →
signature, `Catena.Runtime.ResumptionToken` → resumption, evidence
maps, handler/resume/request expression tags) and on a generic
`{:computation, tag}` for every unevaluated expression form; anything
outside every carrier is `:unknown_form`, which keeps VA-OBL-005's
closed-set property total rather than crash-based.

This is also the first slice whose compiler evidence is mostly
*property-shaped*: the terminal-outcome rule is witnessed over the
shipped C010 stepper (the fixture's `{2, true, 5}` terminal and a
trapping kernel program), and first-classness is witnessed by storage
containers holding handles and closures — the classifier's consumers
(P035 equality, G037 observability) will inherit those witnesses.

## Version and boundary decision

C029 consumes `0.1.25` for the value grammar, the non-value list,
first-classness, the strictness invariant, the terminal contract, and
the classification operation; it adds no JSON AST version, kernel
S-expression version, interface version, artifact version, signature
domain, typing rule, runtime behavior, BEAM representation, manifest
field, or diagnostic family, and amends no retained revision — the
0.1.8 kernel chapters keep their exact-input boundary. Every
predecessor API retains its exact selection. The next unused semantic
patch is `0.1.26`.
