# C132 Progress and Preservation

## Observations

Checklist item P132 is complete as C132, normative source-only
language revision `0.1.45` (86/141 total) — and **Section 16
(formal validation and release gates) opens with its first
closure**. The completed boundary: the effects-and-failure targets
over the shipped handler calculus (installation, resume-once, and
return-clause preservation; effect progress; trap terminality
with kernel-verbatim reasons), the integrated theorem as a
**composed statement** — the standing component theorems (C002
data, C003 conditions, C010 kernel, this slice's effects) plus a
composition lemma that is a **routed proof obligation, never a
claim**, owned by the formal-validation program — and conditional
extensions: public processes on G084/G085's own preservation
statement, foreign values by construction of C067's visible typed
boundary. Zero new diagnostic families, no new public API, no
checker rule changes.

Three implementation notes. First, the **effects witness** is a
minimal kernel handler module (an `Ask` effect through an `AddOne`
handler, `3 → 4` on stepper and BEAM) covering installation,
resume, and return in one program; a planned `plain` variant
(handling a pure literal) rejected as `EFX004` — the handler's
effect must appear in the body's row — and was dropped in favor
of the honest single witness. Second, the **trap witness** reuses
C036's shape (`{:trap, 100, outcome}` on the stepper with the
compiled twin). Third, a **sweep gap surfaced**: the pin sweep's
`c0*` glob does not match the newer `c132_*`/`c140_*` filenames
(c-one, not c-zero), leaving C140's registration test pinning
`0.1.44` — and the fix's first attempt corrupted two lines via a
sed `&` back-reference before the python repair. Future sweeps
must use `c[01]*_*.exs` or sweep the new files explicitly.

The sibling compiler implementation is commit
[`5525662`](https://github.com/pcharbon70/catena/commit/5525662)
on branch `agent/c132-metatheory`, publication pending: the
compiler PR merges into `rewrite` first, then this research
promotion merges, following the established publication order.
