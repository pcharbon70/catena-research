# C033 Branching

## Observations

Checklist item G033 is complete as C033 and normative source-only
language revision `0.1.29`, closing Section 4's gaps — values
(C029), order (C030), bindings (C031), functions (C032), and
branching (C033) now all carry language-level chapters, with the
P029–P038 partials remaining. The completed boundary fixes: match is
the single branch form; the conditional sugar promise fixes that any
future `if` spelling desugars to a Bool-pattern match with shipped
semantics; the consolidated rule table cites C002 (typing, `M001`,
redundancy), C003 (conditions, fallthrough), C010 (commitment),
C029 (skips), C030 (schedules), and C032 (tails) without displacing
any of them; and statement-like control forms are declared absent.
Zero new diagnostic families and no new public API.

Four implementation decisions worth recording. First, the conditional
witness needs a **Bool-typed scrutinee that performs an effect** —
the corpus template's effects all return Int, so the witness family
gains a `flag` operation (Int → Bool) whose handler clause resumes
with `true`; the trace then shows `[:flag, :second]`, proving both
dispatch and that only the selected body's request appears
(commitment). Second, the fallthrough witness cannot use a
**literal-false guard**: the coverage checker classes literal guards
(a false guard makes its clause dead, `M002`), so fallthrough is
witnessed by a *bound-variable* guard (`n < 3` over an Int scrutinee
of 5) — unknown class, coverage continues, second clause taken, with
scrutinee and body effects observable. Third, guard encoding rides
the clause's optional `"guard"` field — the JSON AST's name for C003's
condition — discovered in the decoder rather than assumed. Fourth,
one lifecycle-edit casualty: the `branching` feature block initially
failed to land in `features()` (a multi-edit collision), caught
because the registration test asserts `{:ok, :stable}` — the per-area
`state/2` assertion earning its keep as more than boilerplate.

The sibling compiler implementation is commit
[`221338face094ad9c9306dcf8805a75910b1d1d7`](https://github.com/pcharbon70/catena/commit/221338face094ad9c9306dcf8805a75910b1d1d7)

promise, the consolidated table, and the statement-form absence; it
adds no JSON AST version, kernel S-expression version, interface
version, artifact version, signature domain, typing rule, runtime
behavior, BEAM representation, manifest field, public API name, or
diagnostic family, and amends no retained revision. Every predecessor
API retains its exact selection. The next unused semantic patch is
