# C034 Recursion and Termination

## Observations

Checklist item P034 is complete as C034 and normative source-only
language revision `0.1.31`, the second Section 4 partial to close.
The completed boundary fixes: program recursion is unrestricted —
divergence is non-termination (never a trap, never undefined
behavior), the tail guarantee is the only stack promise, no
expression-level totality checking exists, and any future checker is
an edition-record-gated opt-in analysis; every meta-level evaluator
is total-or-bounded by its own shipped mechanism (conditions acyclic
with `CND004`, specification examples under the fixed 20,000-step
checker, laws with bounded samples); and any recursive-total fragment
— G038 compile-time evaluation foremost — must ship with its
totality-or-boundedness regime in its admitting slice. Zero new
diagnostic families and no new public API.

Three implementation decisions worth recording. First, the
**divergence witness** asserts the stepper's `budget_exhausted`
outcome under an explicitly small budget (500 steps) on an infinite
`spin` loop, run twice for determinism — the definitional machine's
honest report that a non-terminating program is a running program,
with no trap diagnostic anywhere in the result. The `run/4` shape
matters: options are the fourth argument (`run(core, "main", [],
budget: 500)`), not keyword tail on the third — the arity error in
the first draft caught exactly that. Second, the **non-tail witness**
runs a 10,000-deep recursive sum on compiled BEAM (result
50,005,000) — stack-consuming recursion completing on the production
target, beyond what the stepper's 20,000-step budget could cover,
which is itself the point: the reference budget is a reference
machine's limit, not a language limit. Third, the **tail witness**
depth is calibrated to the budget (400 iterations): each kernel
iteration costs several small steps, so the C032 shape's depth had to
shrink from the 5M BEAM witness to a budget-fitting stepper depth —
the two targets deliberately witness different facts (BEAM: constant
stack at scale; stepper: termination within a finite budget).

[`252da7b287dfbfae95056fa778e0b7ce0979599f`](https://github.com/pcharbon70/catena/commit/252da7b287dfbfae95056fa778e0b7ce0979599f),
merged into the `rewrite` integration line by compiler PR
[#111](https://github.com/pcharbon70/catena/pull/111) at merge commit
[`a39289c`](https://github.com/pcharbon70/catena/commit/a39289cd0f0a57dce6bbe5b162174317596e767b).

## Version and boundary decision

C034 consumes `0.1.31` for the stance, the separation table, and the
entry rule; it adds no JSON AST version, kernel S-expression version,
interface version, artifact version, signature domain, typing rule,
runtime behavior, BEAM representation, manifest field, public API
name, or diagnostic family, and amends no retained revision. Every
predecessor API retains its exact selection. The next unused semantic
patch is `0.1.32`.
