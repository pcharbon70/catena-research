# Swift API Design Guidelines

## Reference

Swift project. Swift API Design Guidelines. Swift.org documentation. [Canonical source](https://www.swift.org/documentation/api-design-guidelines/).

Reading locations: Fundamentals; Promote Clear Usage; Use Terminology Well; Argument Labels. Living document accessed 12 September 2026.

## Method

Official prescriptive guidance with call-site examples and naming conventions.

## Findings

The guidance prioritizes clarity at use sites, parameter roles, and avoiding unnecessary words. It permits technical terms where their precise meaning would otherwise be lost.

## Limits

This is ecosystem guidance, not controlled evidence that Swift's syntax or English phrasing is optimal. Method labels and mutation conventions reflect Swift's language model.

## Relevance

Review Catena vocabulary in complete expressions and error messages. Familiarity is valuable only when a name preserves the required behavioral distinction.
