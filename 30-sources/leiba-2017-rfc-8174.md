# RFC 8174: Ambiguity of Uppercase vs Lowercase in RFC 2119 Key Words

## Reference

Barry Leiba. “Ambiguity of Uppercase vs Lowercase in RFC 2119 Key Words.”
RFC 8174, BCP 14, May 2017. DOI
[10.17487/RFC8174](https://doi.org/10.17487/RFC8174).
[RFC Editor edition](https://www.rfc-editor.org/rfc/rfc8174.html).

## Contribution

RFC 8174 updates RFC 2119 by making capitalization semantically decisive. The
special BCP 14 meanings apply only to words written in uppercase; lowercase
occurrences retain ordinary English meaning.

## Method

This procedural Best Current Practice replaces RFC 2119's ambiguous
introductory wording. It does not redefine the individual requirement levels.

## Findings

- Uppercase requirement words provide clarity and consistency but are not
  required for normative prose.
- Only uppercase occurrences receive the specialized standards meaning.
- Lowercase occurrences are ordinary English.
- A document using BCP 14 should state the capitalization convention near its
  governing material.

## Relevance

Catena adopts uppercase-only special force, ordinary lowercase meanings, and
binding declarative prose. That makes validator enforcement precise without
requiring every normative sentence to include a keyword.

## Limits

RFC 8174 does not choose Catena's smaller keyword set or define programming
language behavior classes, invalidity, implementation limits, traps, or
profiles. Its recommended boilerplate is adapted rather than copied.
