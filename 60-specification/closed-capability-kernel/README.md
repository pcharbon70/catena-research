# Closed Capability Kernel Specification

## Purpose

This area defines the `0.1.50` closed identity-row target that makes repeated
escaping comprehension effects executable without changing exact C010.
It follows [Specification Authority](../../SPECIFICATION-AUTHORITY.md),
[Conformance Vocabulary](../../CONFORMANCE-VOCABULARY.md), and
[Implementation Limits](../../IMPLEMENTATION-LIMITS.md).

## What belongs here

The explicit compound-input boundary, identity and scope rules, independent
fragment checking, the comprehension target amendment and artifact exclusions.
General open-row inference remains C005's contract; public grammar remains P109.

## Variability register

No new implementation-defined choice, bounded unspecified presentation,
recommendation or implementation limit is introduced. Standing limits apply.
