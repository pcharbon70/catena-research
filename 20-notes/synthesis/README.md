# Synthesis Snapshots (`20-notes/synthesis`)

## Purpose

This directory holds dated, corpus-wide synthesis snapshots: reports
that step outside a single topic to assess the whole language effort
at one moment — checklist position, normative-area inventory,
cross-cutting guarantees, declared absences, quality-gate results, and
recommended next moves. Each snapshot is frozen to its date and is not
silently updated; a later snapshot supersedes rather than rewrites.

## What belongs here

Put dated status reports and other whole-corpus syntheses here. A
document belongs when its subject is the state of the effort itself
rather than one design question. Topic syntheses arguing a specific
model — the `catena-*.md` design notes — stay in the parent
`20-notes/` directory. Per-slice evidence belongs in
[the journal](../../50-journal/README.md), and topic navigation belongs
in [maps](../../10-maps/README.md).

## Maintaining this index

Add a new snapshot rather than editing an old one; index it here and
update the parent `20-notes/` README if the directory's role changes.
When a snapshot's numbers are superseded, the newer snapshot's
Evidence route becomes the live entry point and the old snapshot stays
as history.
